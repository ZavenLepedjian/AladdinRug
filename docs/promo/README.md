## What is in it

1. **Title**: AladdinRug on a cluttered desktop, the rug rolled up beside the icons.
2. **Roll it out**: the merchant walks in and rolls the rug out over the clutter.
3. **Lift it. Drag it. Fold it.**: real cloth. A scripted hand lifts an edge, folds it over, then drags the whole rug across the desktop. Dust puffs where it lands.
4. **A merchant rolls it up**: the same merchant, the other way round.
5. **Sort the clutter, by file type**: the merchant carries the sample files into folders, one to five at a time, in random order (a 5x time-lapse).
6. **Sweep the folders under the rug**: the broom, and the lumps the folders make under the rug (a 3x time-lapse).
7. **The four rugs**, and the end card.

## It is not a screen recording

Every frame is drawn by AladdinRug's own code (the same cloth physics, rug art, merchant and lumps as the app) onto a **made-up desktop**: its own wallpaper, a plain taskbar and the [sample files](../../samples). Nothing is captured from a real screen, so no real icons, folder names, user names or paths can appear in it. The only real-world text in the video is the sample file names and the repository address on the end card.

The one thing the sorting scene does differently from the app is the stage: the app moves files on your real desktop, the video moves icons on the made-up one. The walking, picking up, carrying and putting down use the same movement code (`Walker`) and the same merchant drawing, and the files are grouped by the same planner (`Organizer.MakePlan`).
